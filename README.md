Controle de Troca de Óleo — Frota
Aplicativo web para cadastro e acompanhamento das trocas de óleo dos veículos da frota da empresa.
🎯 Para que serve
Permite cadastrar cada veículo com seu intervalo de troca e acompanhar, pelo KM atual, quando a próxima troca de óleo está próxima ou já vencida — evitando depender de planilha ou controle manual em papel.
⚙️ Funcionalidades
Cadastro de veículos (placa, modelo/descrição, KM atual, intervalo de troca, KM da última troca)
Atualização de KM do veículo
Registro de nova troca de óleo (zera o contador a partir da nova troca)
Histórico de trocas por veículo
Indicador de status (em dia / próximo / vencido) calculado automaticamente
Busca por placa ou modelo
Edição e exclusão de veículos
Dados salvos localmente no navegador (`localStorage`)
🛠️ Tecnologias
HTML, CSS e JavaScript puro (vanilla JS), sem frameworks ou dependências externas
Armazenamento local via `localStorage`
