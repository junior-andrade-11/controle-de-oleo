# 🚛 Controle de Troca de Óleo — Frota

Aplicativo web para cadastro e acompanhamento das trocas de óleo dos veículos da frota.

## 🎯 Para que serve

Permite acompanhar automaticamente, pelo KM atual, quando a próxima troca de óleo está próxima ou vencida.

## ⚙️ Funcionalidades

- Cadastro de veículos
- Placa, modelo e descrição
- KM atual
- Intervalo de troca
- KM da última troca
- Atualização de KM
- Registro de nova troca de óleo
- Histórico de trocas por veículo
- Status automático: **Em dia / Próximo / Vencido**
- Busca por placa ou modelo
- Edição e exclusão de veículos
- Salvamento local com `localStorage`

## 🛠️ Tecnologias

`HTML` `CSS` `JavaScript` `localStorage`
